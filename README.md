# 미디어허브 랜딩 페이지

언론사가 직접 쓴 기사를 250여 개 제휴 언론사에 동시 송출하는 **미디어허브** 랜딩 페이지입니다.

## 구성

- `index.html` — 단독으로 동작하는 랜딩 페이지 (HTML/CSS/JS 한 파일, 빌드 불필요)
- `design/Main.dc.html` — Claude 디자인 캔버스 원본 소스

## 실행

`index.html`을 브라우저로 열면 됩니다. GitHub Pages나 Vercel에 그대로 올려도 동작합니다.

## 포함된 인터랙션

- 히어로 등장 애니메이션, 떠다니는 아이콘·카드, 검색창 커서 깜빡임
- 스크롤 시 섹션·카드 순차 등장, 대화 말풍선 순차 표시
- 레이더 차트 펼침, STEP 휴대폰 화면 내부 애니메이션, 리포트 막대 차오름
- 통계 숫자 카운트업, 0원 팝 애니메이션
- 버튼·카드·메뉴·탭·입력칸 호버/포커스 효과
- 기사 유형 탭 전환, 서비스 카드 클릭 시 문의폼 관심 상품 자동 체크
- `prefers-reduced-motion` 설정 시 애니메이션 자동 비활성화

## 교체가 필요한 자리

- `[ … 이미지 ]` 표시된 이미지 영역
- 기사 유형 6종(기획기사·인터뷰 등) 예시 문구
- 고객만족도·재계약률 근거, 지면기사 게재 매체 등 "확인 중" 문구
- 문의폼은 샘플이며 실제 접수 기능은 없습니다
